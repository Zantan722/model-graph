# Model Graph 0.7.1

這個版本讓 PUML 匯入少擋一些合法寫法，並在擋下來時說清楚原因。

## 更新

- PUML 編輯器新增「格式化」：重排縮排、統一巨集參數間隔、收合多餘空行。只調整排版，不重排順序、不改語意、不修語法錯誤。
- C4 邊界群組（`Enterprise_Boundary`、`System_Boundary`、`Container_Boundary`、`Boundary`）不再被擋下。群組內的元素與跨越群組的關係都會保留，群組本身不會變成節點；大括號不配對仍會標出行號。
- C4 巨集參數數量不符時，錯誤訊息改為指名該巨集實際有的欄位。`Person`／`System` 沒有技術欄位，訊息會直接建議改用 `Container`／`Container_Ext`，不再列出不存在的「技術」。
- 具名參數（`$sprite`、`$tags`、`$link` 等）改用獨立訊息，不再併入參數數量錯誤。

## 安裝

- macOS Apple Silicon：下載 `Model-Graph-0.7.1-mac-arm64.dmg`，開啟後將 App 拖入 Applications。ZIP 為替代下載。
- Windows x64：下載 `Model-Graph-0.7.1-win-x64.exe`，執行安裝程式。
- Claude Code／Codex CLI 需另外安裝並登入，再於 App 設定選擇提供者。

## 驗證與限制

20 組自動測試、TypeScript 檢查及 Electron 操作測試通過。格式化以「對九種標準匯出格式化後必須一字不差」為主要檢核，並在 Electron 視窗中實際點擊按鈕確認；邊界群組涵蓋四種巨集名稱、巢狀與大括號不配對。此次未用真實模型重驗生成品質。

邊界群組只是解析時的透明群組。畫布沒有群組概念，所以不會畫出邊界框，重新匯出時群組會消失，這點會以轉換提醒顯示。

格式化不會修正語法錯誤：格式化後仍然無法匯入的檔案，錯誤數量與內容維持不變。

macOS 安裝檔未簽章及公證；Windows 安裝檔未簽章，為 macOS 交叉建置，尚未在 Windows 實機驗證。系統可能顯示安全性提醒。

SVG 匯出只內嵌計算後的樣式，不內嵌字型。在沒有相同字型的機器上開啟，文字會換成替代字型，排版寬度可能改變；需要固定外觀請用 PNG 或 JPG。

PUML 編輯後會標準化輸出，原始樣式與一般註解可能改變；不是任意 PlantUML 語法的無損編輯器。來源摘錄會隨 PUML 匯出，可能包含程式片段。
