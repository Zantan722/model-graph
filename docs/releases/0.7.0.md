# Model Graph 0.7.0

這個版本補上圖片匯出，並讓畫布可以讓出面板空間。

## 更新

- 匯出 PNG、JPG、SVG：輸出整張圖，不受目前縮放與捲動位置影響。PNG／JPG 以 2 倍解析度輸出，JPG 為白底，SVG 保持透明背景。
- 匯出前移除編輯器專用的顯示：連線圓點、連線預覽，以及選取、鍵盤聚焦與滑鼠停留的高亮都不會被寫進檔案。
- 上方工具列、左側助理與右側屬性可分別收合；「專注模式」一次全收，再按一次還原成先前的組合。收合狀態保存在本機，畫布會自動重新符合畫面。
- 桌面版新增「檔案 → 匯出 PNG／JPG／SVG／JSON」與「檢視 → 專注模式」，快捷鍵為 Cmd/Ctrl+S（PNG）、Cmd/Ctrl+Shift+S（SVG）與 Cmd/Ctrl+\。
- 桌面版存檔寫入未完成時會顯示錯誤，不再只由畫面回報成功；取消存檔不視為錯誤。

## 安裝

- macOS Apple Silicon：下載 `Model-Graph-0.7.0-mac-arm64.dmg`，開啟後將 App 拖入 Applications。ZIP 為替代下載。
- Windows x64：下載 `Model-Graph-0.7.0-win-x64.exe`，執行安裝程式。
- Claude Code／Codex CLI 需另外安裝並登入，再於 App 設定選擇提供者。

## 驗證與限制

19 組自動測試、TypeScript 檢查及 Electron 操作測試通過。操作測試涵蓋三種圖片格式實際寫出檔案、SVG 內容保有節點與樣式且不含選取或停留高亮、收合面板後畫布變寬並可還原，以及「檔案」與「檢視」選單確實驅動畫面。此次未用真實模型重驗生成品質。

SVG 只內嵌計算後的樣式，不內嵌字型。在沒有相同字型的機器上開啟，文字會換成替代字型，排版寬度可能改變；需要固定外觀請用 PNG 或 JPG。

macOS 安裝檔未簽章及公證；Windows 安裝檔未簽章，為 macOS 交叉建置，尚未在 Windows 實機驗證。系統可能顯示安全性提醒。

PUML 編輯後會標準化輸出，原始樣式與一般註解可能改變；不是任意 PlantUML 語法的無損編輯器。來源摘錄會隨 PUML 匯出，可能包含程式片段。
