# Model Graph 0.6.0

這個版本將主要流程簡化為選專案、描述需求、看圖及修改。

## 更新

- 合併需求輸入入口，CLI 與模型設定預設收合；探索需求先列候選，勾選後才讀取相關實作並產圖。
- 選取節點或關係後可局部修改，保留其他原有內容與位置。
- 畫布修改反映於圖表清單，保留最近 10 個修改前版本；產圖期間畫布有變更時，不直接覆蓋。
- 原生開啟與儲存 PUML：寫入前比較內容，原檔被外部修改時停止覆寫。
- 節點與關係可查看來源摘錄；引用路徑與行號對照本次讀取來源，不代表推論一定正確。
- 移除主介面的分析缺口，單次 CLI 等待延長至 10 分鐘，取消整批 30 分鐘強制中止。

## 安裝

- macOS Apple Silicon：下載 `Model-Graph-0.6.0-mac-arm64.dmg`，開啟後將 App 拖入 Applications。ZIP 為替代下載。
- Windows x64：下載 `Model-Graph-0.6.0-win-x64.exe`，執行安裝程式。
- Claude Code／Codex CLI 需另外安裝並登入，再於 App 設定選擇提供者。

## 驗證與限制

18 組自動測試、TypeScript 檢查及 Electron 操作測試通過，包含五種版面尺寸、圖表切換保留修改、PUML 開啟與儲存確認。此次未用真實模型重驗生成品質。

macOS 安裝檔未簽章及公證；Windows 安裝檔未簽章，為 macOS 交叉建置，尚未在 Windows 實機驗證。系統可能顯示安全性提醒。

PUML 編輯後會標準化輸出，原始樣式與一般註解可能改變；不是任意 PlantUML 語法的無損編輯器。來源摘錄會隨 PUML 匯出，可能包含程式片段。
